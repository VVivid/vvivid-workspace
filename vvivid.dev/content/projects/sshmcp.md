SSHMCP provides an authenticated MCP gateway and a native Go execution runner for configured SSH targets. Persistent Bash connections support durable jobs, bounded output, idempotency, and independent cancellation.

Browse the [source code and documentation](https://github.com/VVivid/vvivid-workspace/tree/main/SSHMCP).
